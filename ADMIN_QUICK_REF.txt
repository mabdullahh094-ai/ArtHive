# Admin Dashboard - Quick Reference Card

## 🎯 THE ANSWER: Where is Admin Dashboard?

**URL**: `http://localhost:3000/admin`

**Access**: After you login as admin user

---

## ⚡ 5-Step Quick Start

### 1️⃣ Create Admin
```bash
cd arthive-backend
node scripts/createAdmin.js admin@test.com Test@1234 Admin User
```

### 2️⃣ Start Servers
```bash
# Terminal 1
npm start  # in arthive-backend (port 3001)

# Terminal 2  
npm start  # in arthive-frontend (port 3000)
```

### 3️⃣ Open Login
```
http://localhost:3000/login
```

### 4️⃣ Login as Admin
- Email: `admin@test.com`
- Password: `Test@1234`

### 5️⃣ See Admin Dashboard
- **Automatic redirect** to `http://localhost:3000/admin`
- **Or** click "Admin Dashboard" from header menu

---
